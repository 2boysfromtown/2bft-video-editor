# Music library for edits: free, Indian, platform, paid and AI sources

This list covers 66 music sources Claude can use when editing Reels, Shorts, YouTube long-form and client ads for a Chennai creator working in Tamil, Hindi and English. Each entry was checked live on **28 Oct 2026** with curl, WebFetch or the built-in browser, and the Verified column says how. "2nd-hand" means the claim comes only from third-party articles because the official page could not be read. "Not verified" means nothing was checked.

**Check your own music pack first:** `<asset store>\music\README.md`, if you keep one: tracks sorted by mood, with BPM, drop times (`scan.json`, from `quest-lab-editor/engine/tools/music_scan.py`) and ready credit lines. Add new tracks only with the user's yes. For what is trending, see `trending-music.md`.

**How to read the columns**
- **Content ID risk:** Low means the owner says the music won't be claimed. Medium means some tracks are fingerprinted, or a claim fires if the credit is missing. High means claims are routine and you have to dispute them with a licence.
- **Client ads OK?** Means music in a paid ad or a video you make for a paying client.
- **Access:** "none" means no login or key. Claude never signs up or enters keys. If a source needs an account, the user signs in first, using the built-in browser's saved sign-in.

**Licence rules Claude applies to every track, whatever the source**
1. **NC (NonCommercial):** not allowed in monetised videos or client ads.
2. **ND (NoDerivatives):** not allowed in any video. Under CC, putting music in sync with video counts as an adaptation. Openverse's `license_type=commercial` still returns `by-nd` tracks, so add `modification`.
3. **SA (ShareAlike):** your whole video would have to carry CC BY-SA. Never use it in client work.
4. **FMA-Limited:** personal listening only, never in a video.
5. **"Content ID Registered" or "AI generated" badges (Pixabay):** expect a claim, or a weaker rights position. Skip these tracks for client ads.
6. **Credit with a per-video code (Bensound, Uppbeat free):** the credit goes in each video's description exactly as given. A Reel caption has no room for a long code, so prefer no-credit sources for Reels.
7. **Keep proof:** save the licence page or certificate PDF next to the project in `_licences/`. Dispute a claim with it, never ignore one.

## Fetch recipes (all tested 28 Oct 2026)

Quickest route: `python -I <skills>/asset-library/scripts/find_assets.py music "<mood or tag>"` searches Mixkit (ads OK), NCS, Incompetech, ccMixter and Openverse music in parallel and prints licence + direct file URL per track (Mixkit takes a tag slug such as `corporate`, `hip-hop`, `cinematic`; Incompetech matches title, feel and instruments such as `sitar`). The recipes below were all tested on 28 Oct 2026 with Range requests. Openverse can 504; retry if so.

Save downloads into a fresh folder per project, e.g. `<project>\_music\`, and the licence or credit text into `<project>\_licences\<track>.txt`.

```bash
UA="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/130 Safari/537.36"

# Incompetech: catalogue JSON, then mp3 (URL-encode spaces)
curl -s "https://incompetech.com/music/royalty-free/pieces.json" -o pieces.json
curl -L -o "Vadodora.mp3" "https://incompetech.com/music/royalty-free/mp3-royaltyfree/Vadodora.mp3"

# NCS: search page -> data-url (S3 full mp3)
curl -s -A "$UA" "https://ncs.io/music-search?q=phonk&genre=&mood=" | grep -oE 'data-url="https://ncsmusic[^"]+\.mp3"' | head

# ccMixter: API, then the mp3 (Referer REQUIRED, else 403)
curl -s "https://ccmixter.org/api/query?f=json&tags=instrumental&lic=by&limit=5&sort=rank"
curl -L -A "$UA" -e "https://ccmixter.org/" -o track.mp3 "https://ccmixter.org/content/<user>/<file>.mp3"

# Mixkit: tag page -> assets mp3
curl -s -A "$UA" "https://mixkit.co/free-stock-music/tag/corporate/" | grep -oE 'https://assets\.mixkit\.co/music/[0-9]+/[0-9]+\.mp3' | sort -u

# FMA: artist/album page -> data-track-info fileUrl (no login)
curl -s -A "$UA" "https://freemusicarchive.org/music/lee-rosevere/" | grep -oE 'files\.freemusicarchive\.org\\/[^"]+\.mp3' | sed 's#\\/#/#g'

# Fesliyan: category page has direct musicfiles mp3 (or download-link.php?src=i&id=N -> 302)
curl -s -A "$UA" "https://www.fesliyanstudios.com/royalty-free-music/downloads-c/indian-music/66" | grep -oE 'https://www\.fesliyanstudios\.com/musicfiles/[^"]+\.mp3' | sort -u

# Chosic: download page -> wp-content mp3 + licence line
curl -s -A "$UA" "https://www.chosic.com/download-audio/24642/" | grep -oE 'https://www\.chosic\.com/wp-content/uploads/[^"]+\.mp3' | head -1

# Looperman: preview mp3 needs Referer
curl -L -A "$UA" -e "https://www.looperman.com/loops?keys=tabla" -o loop.mp3 "https://www.looperman.com/media/loops/<uid>/looperman-l-....mp3"

# Audionautix / Josh Woodward: predictable direct mp3
curl -L -A "$UA" -o FallingSky.mp3 "https://audionautix.com/Music/FallingSky.mp3"
curl -L -A "$UA" -o Wade.mp3 "https://www.joshwoodward.com/mp3/JoshWoodward-Wade.mp3"

# Openverse (no key): commercial AND modifiable (excludes ND)
curl -s --max-time 60 "https://api.openverse.org/v1/audio/?q=piano&license_type=commercial,modification&category=music&page_size=20"

# Internet Archive: search -> file list -> download
curl -s "https://archive.org/advancedsearch.php?q=subject%3A(tabla)+AND+mediatype%3Aaudio+AND+licenseurl%3A*publicdomain*&fl%5B%5D=identifier&fl%5B%5D=licenseurl&rows=50&output=json"
curl -s "https://archive.org/metadata/<identifier>"        # then https://archive.org/download/<identifier>/<file>

# Wikimedia Commons: audio search with licence
curl -s -A "ClaudeAssetBot/1.0 (personal editing)" "https://commons.wikimedia.org/w/api.php?action=query&format=json&generator=search&gsrsearch=filetype:audio%20tabla&gsrnamespace=6&gsrlimit=20&prop=imageinfo&iiprop=url|extmetadata&iiextmetadatafilter=LicenseShortName|Artist"

# Jamendo stream without a key (ID taken from Openverse results)
curl -L -o jam.mp3 "https://prod-1.storage.jamendo.com/?trackid=923463&format=mp32"
```

Python helper (same logic as the test script):
```python
import json, re, urllib.request
UA = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/130 Safari/537.36"
def get(url, referer=None):
    h = {"User-Agent": UA, **({"Referer": referer} if referer else {})}
    return urllib.request.urlopen(urllib.request.Request(url, headers=h), timeout=60).read()
# Incompetech: sitar tracks
pieces = json.loads(get("https://incompetech.com/music/royalty-free/pieces.json"))
sitar = [p for p in pieces if "sitar" in (p.get("instruments") or "").lower()]
# ccMixter: CC BY instrumentals with mp3 links (download with referer=t["file_page_url"])
tracks = json.loads(get("https://ccmixter.org/api/query?f=json&tags=instrumental&lic=by&limit=20&sort=rank"))
# FMA: parse data-track-info JSON for fileUrl
html = get("https://freemusicarchive.org/music/lee-rosevere/").decode("utf-8", "ignore")
```
